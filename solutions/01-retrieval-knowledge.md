# 模式 1：非结构化语料上的检索问答（RAG）

> 把企业里"人找不到、找到了也不敢用"的文档，变成一个能给出**可点击出处**的问答入口。

| | |
|---|---|
| **典型输入** | 研报、招股书、产品手册、合规文件、历史工单、会议纪要 |
| **典型输出** | 带引用的答案 + 原始段落定位 |
| **适用** | 语料稳定、有明确答案、错了代价可控（辅助人类决策） |
| **不适用** | 需要实时数据、需要执行动作、语料本身是错的/过期的 |
| **本库案例** | [摩根士丹利](../cases/finance/morgan-stanley-ai-assistant.md)、[Lowe's](../cases/retail/lowes-mylow.md) |

---

## 1. 参考架构

```
用户提问
  ↓
① 意图与权限判定 ──→ 越权/无答案 ──→ 拒答（返回"查不到"+ 建议联系谁）
  ↓
② 召回：向量检索 ∥ 关键词检索（BM25）
  ↓
③ 重排（cross-encoder 或 LLM rerank），取 top-k
  ↓
④ 组装上下文：原文段落 + 元数据（文档名/版本/生效日期/负责人）
  ↓
⑤ 生成：每句话必须绑定一个来源段落 ID
  ↓
⑥ 引用校验：答案里出现但检索结果里没有的数字 → 拦下重写
  ↓
⑦ 输出 + 埋点（查了什么、点了哪条引用、有没有追问）
```

**第 ① 步的位置决定生死**：权限过滤必须在**召回之前**做。先检索再过滤，向量库里已经查到了不该看的内容，任何"后置裁剪"都只是把泄露藏起来。

## 2. 组件与关键选择

| 层 | 做什么 | 关键选择 | 常见错误 |
|---|---|---|---|
| 解析 | PDF/网页/Excel → 结构化块 | 保留表格结构与标题层级；扫描件必须 OCR + 人工抽检 | 按固定 512 token 切块，把一张表切成三片 |
| 索引 | 向量 + 关键词双路 | 混合检索几乎总是优于纯向量；专有名词、型号、法条编号靠关键词 | 只做向量，导致"第 4.2 条"永远召不回 |
| 权限 | ACL 映射到检索过滤 | 与 AD/SSO 同源，权限变更要能即时生效 | 权限写死在索引里，员工调岗后仍能看老部门文档 |
| 重排 | 精排 top-50 → top-5 | 用真实提问做评测集，不要用文档标题造问题 | 用 LLM 当重排器但不设超时，P99 飙到 20 秒 |
| 生成 | 带引用作答 | 强制"无来源不输出数字" | 允许模型自由发挥统计口径 |
| 拒答 | 阈值 + 兜底话术 | 明确"我不知道"比编一个更像企业级产品 | 把拒答率当负面指标压到 0 |

## 3. 集成点：成败在这里

**案例里最值得抄的一条**：摩根士丹利把这个助手放进顾问**已有的工作流**（写邮件、准备客户会议），而不是新建一个聊天网站。Lowe's 则把它挂在店员已有的手持终端和 App 里。

判断标准很简单：**用户会不会为了用它而多开一个窗口？** 会，就已经失败了。

## 4. 人机分工

| 环节 | AI | 人 |
|---|---|---|
| 找文档 | ✅ 召回 + 排序 | — |
| 起草答复 | ✅ 生成草稿 | ✅ 事实与合规复核 |
| 对外发送 | ❌ | ✅ 必须人签 |
| 语料维护 | ⚠️ 发现过期只能提示 | ✅ 定归属人、定复核周期 |

最后一行最容易被忽略：**文档新鲜度是运营问题，不是模型问题。** 没有归属人和复核周期的知识库，RAG 上线三个月后开始系统性答错。

## 5. 怎么评测（含口径陷阱）

| 指标 | 怎么算 | 陷阱 |
|---|---|---|
| 召回率 recall@k | 用 100–300 条真实提问 + 标注正确段落 | 用文档标题反造问题 → 虚高 20 分 |
| 引用正确率 | 抽样看答案的每个数字能否在引用段落找到 | 只测"像不像"，不测"对不对" |
| 采纳率 | 区分**席位开通率**与**周活跃率** | 摩根士丹利的 ">98%" 分母是顾问团队，不是个人使用频次 |
| 覆盖度 | 有多少文档真的进了索引 | "文档可达 20%→80%" 说的是覆盖，不是准确率 |

**一条硬提醒**：覆盖度和准确率是两件事。把 80% 的文档接进索引，只说明接进来了。

## 6. 真实失败模式

1. **Demo 阶段不问权限**，POC 通过、安全评审卡死——这是金融行业最常见的死法。
2. **语料过期无人管**，模型忠实地引用三年前的费率表。
3. **只测满意度**，上线后老板问"到底省了多少时间"，答不出来。
4. **把"能答"当"能替人做决定"**，从辅助变成越权。
